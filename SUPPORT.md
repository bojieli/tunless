# Support

Use GitHub Discussions for configuration questions, platform comparisons, and
help interpreting diagnostics. Search existing discussions and issues first.
Include the Tunless commit or version, OS and architecture, Linux kernel and
cgroup mode where relevant, container engine, upstream proxy, redacted logs,
and the JSON from `tunless --check`.

Use the bug template only for reproducible defects. Feature requests should
explain the user problem and platform constraints. Security vulnerabilities
must use GitHub private vulnerability reporting as described in `SECURITY.md`.

Support is best-effort. The documented compatibility matrix is authoritative;
untested platforms and unpublished source snapshots have no stability promise.
